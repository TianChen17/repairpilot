A single dbt column rename can break revenue models and executive dashboards. RepairPilot stops that change before merge.

This is not another incident chatbot. It blocks, repairs, proves, requests human authority, and writes reusable knowledge back to DataHub.

A deterministic policy scores the change high risk: one hundred out of one hundred. The model cannot lower this score, bypass approval, or publish. If DataHub is unavailable, RepairPilot fails closed.

Only then does owner approval unlock. A rejection keeps the release blocked and creates no pull request.

The output is a real public GitHub draft pull request: four files, the alias, migration, test, and guide. GitHub Actions rebuilds everything and stays green.
